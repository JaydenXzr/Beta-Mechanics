What we are actually building

One page is a set
of connected pieces.

The visible website is not one huge block of code. The header is HTML, its appearance is CSS, and its mobile button is JavaScript. They connect through names: an HTML element has a class, CSS selects that class, and JavaScript can find that same element.

HTML

Creates the actual elements: a header, navigation links, an image, cards, and buttons.

CSS

Selects those elements and controls their size, color, position, spacing, and mobile layout.

JavaScript

Finds some of those elements and changes their state when a person clicks, types, or submits.

How to use this page

Copy a complete code block into the named file, save it, and refresh the browser. Then change one value and refresh again. When a code block says “add this to the existing file,” do not erase the rest of that file.

01

Start every new page here

The page shell

This is the smallest useful starting document for a new page. Paste it into a new file beside index.html, for example my-page.html.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="theme-color" content="#111820">
    <title>Beta Mechanic | My Page</title>
    <link rel="stylesheet" href="styles.css">
    <script src="site.js" defer></script>
</head>
<body class="site-page">
    <!-- Put the shared header here. -->
    <header class="site-header">...</header>

    <main>
        <h1>My page heading</h1>
        <p>My page content goes here.</p>
    </main>

    <!-- Put the shared footer here. -->
    <footer class="site-footer">...</footer>
</body>
</html>

lang="en" tells browsers and screen readers that the page language is English.

charset="UTF-8" supports punctuation and symbols used in the page.

The viewport line makes a phone use its real screen width instead of pretending it is a wide desktop.

href="styles.css" loads the same stylesheet used by the other pages. The path is relative to this HTML file.

src="site.js" loads the shared interactions. defer waits until the HTML has been parsed before running the script.

class="site-page" is important: many design rules start with .site-page, so they only apply to the redesigned site pages.

<main> holds the unique content of this page. There should generally be one main content area per page.

--lime and --deep are CSS variables. Later rules can reuse them with var(--lime); changing one variable changes the whole theme.

overflow-x: hidden prevents a decorative effect from creating a sideways scrollbar. It does not mean “hide all content.”

min-height: 690px makes the header tall but still allows it to grow if its content needs more space.

display: flex with flex-direction: column puts the nav, hero, and bottom meta strip in a vertical stack.

background-image accepts multiple layers. The first gradient is drawn on top of the second gradient, and both are on top of the Jesko photo.

The dark gradient is important: without it, white hero text could disappear against bright parts of the photo.

url(...) points from styles.css into the asset folder. If the filename is wrong, the fallback background color still appears but the photo will not.

background-position: center 52% centers the photo and nudges its vertical crop. Try center, center 40%, or center 65%.

background-size: cover fills the header without stretching the image. Cropping is expected because the photo and header usually have different shapes.

width: min(1380px, 100%) means “use at most 1380px, but never wider than the parent.”

margin: 0 auto centers a fixed/max-width block horizontally.

Flexbox justify-content: space-between pushes the brand and nav toward opposite sides. align-items: center aligns them vertically.

The last selector .site-page .nav-links a.nav-cta is more specific than the general navigation-link selector, so it can give the call-to-action its own appearance.

What does the selector mean?

Read from left to right: find an element with class nav-cta that is an a link, inside an element with class nav-links, inside an element with class site-page. Spaces mean “somewhere inside.” No space would mean the same element has both classes.

The Home page save toggle

This is the button HTML the script acts on. aria-pressed starts at false because the car is not saved yet.

<button class="favorite-button" type="button"
        aria-pressed="false">
    <span aria-hidden="true">☆</span> Save the Jesko
</button>
document.querySelectorAll(".favorite-button").forEach((button) => {
    button.addEventListener("click", () => {
        const isSaved =
            button.getAttribute("aria-pressed") === "true";
        button.setAttribute("aria-pressed", String(!isSaved));
        button.querySelector("span").textContent =
            isSaved ? "☆" : "★";
        button.lastChild.textContent =
            isSaved ? " Save the Jesko" : " Jesko saved";
    });
});

This only runs on a page with a .favorite-button. It flips the accessible pressed state, changes the star, and changes the label. The condition ? valueA : valueB expression is called a ternary: it chooses one of two values. This save is temporary; refresh the page and it resets because nothing stores it.

Exact code from site.js

The mobile menu JavaScript

The desktop navigation is visible by default. On a small screen CSS hides the link list and shows the menu button. This JavaScript adds or removes the is-open class when the button is clicked.

document.querySelectorAll(".menu-toggle").forEach((toggle) => {
    const menu = document.getElementById(
        toggle.getAttribute("aria-controls")
    );

    if (!menu) {
        return;
    }

    const closeMenu = () => {
        toggle.setAttribute("aria-expanded", "false");
        menu.classList.remove("is-open");
    };

    toggle.addEventListener("click", () => {
        const isOpen =
            toggle.getAttribute("aria-expanded") === "true";
        toggle.setAttribute("aria-expanded", String(!isOpen));
        menu.classList.toggle("is-open", !isOpen);
    });

    menu.querySelectorAll("a").forEach((link) => {
        link.addEventListener("click", closeMenu);
    });

    document.addEventListener("keydown", (event) => {
        if (event.key === "Escape") {
            closeMenu();
        }
    });
});

document means the current web page. querySelectorAll(".menu-toggle") finds every button with that class.

forEach((toggle) => { ... }) runs the block once per matching button. toggle is the current button being handled.

getAttribute("aria-controls") reads the text primary-links from the button. getElementById(...) finds the menu with that id.

if (!menu) return; is a safety check. If there is no matching menu, stop instead of trying to modify a missing element.

closeMenu is a function stored in a variable. It changes the accessibility state back to closed and removes the class that makes the menu visible.

addEventListener("click", ...) says “run this function when the button is clicked.”

=== checks equality. The result is either true or false. The comparison checks whether the menu is currently marked open.

!isOpen means “the opposite of isOpen.” If it was closed, the new state is open.

setAttribute updates aria-expanded. String(...) turns the boolean into the text values HTML expects: "true" or "false".

classList.toggle("is-open", !isOpen) adds the class when the second argument is true and removes it when false.

The next loop attaches closeMenu to every menu link, so choosing Home or Gallery closes the mobile menu.

The final listener watches keyboard events. If the pressed key is Escape, the same close function runs.

At desktop width the button has display: none; the links are already visible. Inside the phone media query, the button becomes display: flex. The three empty spans become the three horizontal lines of the hamburger icon; :not(.visually-hidden) leaves the hidden spoken label alone.

The menu uses position: absolute so it can open over the page rather than pushing the hero down. top: calc(100% - 1px) places its top at the bottom edge of the navigation. display: none hides the links until JavaScript adds is-open; that second selector means “an element with both nav-links and is-open classes.”

Gallery JavaScript

First, the filter buttons need matching values

<button class="filter-button"
        data-filter="all" aria-pressed="true">
    All stories
</button>
<button class="filter-button"
        data-filter="design" aria-pressed="false">
    Design
</button>
<button class="filter-button"
        data-filter="engineering" aria-pressed="false">
    Engineering
</button>

<article class="collection-card"
         data-category="design">...</article>
<article class="collection-card"
         data-category="engineering">...</article>

The button has a data-filter value; a card has a data-category value. The words must match for that card to remain visible. The “All stories” button is a special option that matches every card.

This is the filter logic from site.js

const filterButtons =
    document.querySelectorAll(".filter-button");
const collectionCards =
    document.querySelectorAll(".collection-card");

if (filterButtons.length && collectionCards.length) {
    const emptyMessage =
        document.querySelector(".empty-filter");

    filterButtons.forEach((button) => {
        button.addEventListener("click", () => {
            const filter = button.dataset.filter;
            let visibleCount = 0;

            filterButtons.forEach((filterButton) => {
                const isActive = filterButton === button;
                filterButton.classList.toggle("is-active", isActive);
                filterButton.setAttribute(
                    "aria-pressed", String(isActive)
                );
            });

            collectionCards.forEach((card) => {
                const isVisible =
                    filter === "all" ||
                    card.dataset.category === filter;
                card.hidden = !isVisible;
                visibleCount += Number(isVisible);
            });

            emptyMessage.hidden = visibleCount > 0;
        });
    });
}

const stores a reference that will not be reassigned. querySelectorAll returns all matching buttons/cards.

&& means “and.” The outer if prevents setup unless the current page has both filter buttons and cards. That lets the shared script load safely on other pages.

button.dataset.filter reads the clicked button's data-filter attribute.

let visibleCount = 0 makes a counter we can increase as visible cards are found. let is used because this value changes.

filterButton === button checks whether the button in the loop is the same actual element as the clicked button. That one gets the active visual style and aria-pressed="true".

filter === "all" || ... uses ||, meaning “or.” Show the card if the filter is All, or if its category matches the chosen filter.

card.hidden = !isVisible uses the browser's built-in hidden state. A true hidden value removes the card from display.

Number(isVisible) turns true into 1 and false into 0, letting the visible-card count increase by the right amount.

The empty-message line shows the message only when zero cards matched: visibleCount > 0 is false, so hidden becomes false.

Then copy the right image into the dialog

const imageDialog =
    document.querySelector(".image-dialog");

if (imageDialog) {
    document.querySelectorAll(".image-open").forEach((button) => {
        button.addEventListener("click", () => {
            const sourceImage = button.querySelector("img");
            const cardTitle =
                button.closest(".collection-card")
                      .querySelector("h3");
            const dialogImage =
                imageDialog.querySelector("img");
            const dialogTitle =
                imageDialog.querySelector("p strong");

            dialogImage.src = sourceImage.src;
            dialogImage.alt = sourceImage.alt;
            dialogTitle.textContent = cardTitle.textContent;
            imageDialog.showModal();
        });
    });
}

if (imageDialog) checks the dialog exists before trying to use it. On pages without a gallery, there is no dialog and the code is skipped.

button.querySelector("img") finds the image inside the button that was clicked.

closest(".collection-card") walks upward from the button to its card. Then querySelector("h3") finds that card's title.

.src and .alt are image properties. Copying both means the modal uses the matching photo and its description.

textContent copies only text, not HTML markup. It safely puts the clicked card's heading into the dialog title.

showModal() opens the native dialog above the rest of the page.

Close the dialog by button or backdrop

imageDialog.querySelector(".dialog-close").addEventListener("click", () => {
    imageDialog.close();
});

imageDialog.addEventListener("click", (event) => {
    if (event.target === imageDialog) {
        imageDialog.close();
    }
});

The close button calls the dialog's close() method. Clicking elsewhere in the dialog runs the second listener, but it closes only when event.target is the dialog itself. A click on the image or caption has a different target, so it does not accidentally close the viewer. The native dialog also closes with Escape.

Contact form JavaScript

First the HTML fields must have labels, ids, and names. for must match the input's id. The name is the key JavaScript uses to retrieve its value.

<label for="email">Email address</label>
<input id="email" name="email"
       type="email" required>

<label for="topic">What are we talking about?</label>
<select id="topic" name="topic" required>
    <option value="" selected disabled>Pick a topic</option>
    <option>My dream garage</option>
</select>

<label for="message">Your message</label>
<textarea id="message" name="message"
          maxlength="600" required></textarea>

<button type="submit">Prepare my message</button>
<div id="form-feedback" role="status"
     aria-live="polite" hidden></div>

The first option in the select has an empty value, so required forces the visitor to choose a real topic. The feedback container starts with hidden, and JavaScript reveals it after a valid submit.

Character count and submit

const contactForm = document.querySelector("#garage-contact");

if (contactForm) {
    const messageField = contactForm.elements.message;
    const messageCount = document.querySelector("#message-count");
    const feedback = document.querySelector("#form-feedback");
    const copyButton = document.querySelector("#copy-message");
    let preparedMessage = "";

    messageField.addEventListener("input", () => {
        messageCount.textContent = String(messageField.value.length);
    });

    contactForm.addEventListener("submit", (event) => {
        event.preventDefault();

        if (!contactForm.reportValidity()) {
            return;
        }

        const formData = new FormData(contactForm);
        preparedMessage = [
            `Name: ${formData.get("name")}`,
            `Email: ${formData.get("email")}`,
            `Topic: ${formData.get("topic")}`,
            "",
            String(formData.get("message"))
        ].join("\n");

        feedback.dataset.error = "false";
        feedback.textContent =
            "Your message is prepared below. It has not been sent because this site does not have a message service connected.";

        const preview = document.createElement("pre");
        preview.className = "prepared-message";
        preview.textContent = preparedMessage;
        feedback.append(preview);
        feedback.hidden = false;
        copyButton.hidden = false;
    });

    copyButton.addEventListener("click", async () => {
        try {
            await navigator.clipboard.writeText(preparedMessage);
            feedback.dataset.error = "false";
            feedback.firstChild.textContent =
                "Copied to your clipboard. Your message has not been sent.";
        } catch (error) {
            feedback.dataset.error = "true";
            feedback.firstChild.textContent =
                "Clipboard access was blocked. You can select and copy the prepared message shown below.";
        }
    });
}

querySelector("#garage-contact") uses # because garage-contact is an id, not a class.

contactForm.elements.message finds the form field whose name is message.

The input event fires as the visitor types. value.length counts characters and textContent updates the visible counter.

submit runs when the visitor submits. preventDefault() prevents the browser's normal form navigation.

reportValidity() asks the browser to check required and type="email". If invalid, return stops the rest of the function.

new FormData(contactForm) collects the form values. formData.get("email") reads the field with name="email".

The square brackets create an array of message lines. .join("\\n") joins them with line breaks.

This only creates and displays a preview. It does not send anything. Sending requires a backend or form service.

async lets this function wait for the clipboard operation. await pauses until the browser reports success or failure. try runs the successful path; catch handles a browser refusing clipboard access. firstChild.textContent replaces only the feedback's first text node, keeping the prepared message preview visible. data-error lets CSS distinguish success and failure.

Important form limitation

Do not paste private email passwords, secret API keys, or credentials into site.js. Browser code is visible to visitors. To truly send a form, connect it to a trusted service or server that handles submissions safely.

When the page does not look right

Debugging this project

Image is broken

Check the filename and folder. From an HTML file at the project root, use assets/images/name.jpg. Keep spaces and capitals exactly as they appear in the file's name.

CSS does nothing

Check that the HTML has the class you selected. A CSS class selector starts with a dot: .feature-copy. An id selector starts with a hash: #garage-contact.

Menu won't open

Check that the button has aria-controls="primary-links", the list has id="primary-links", and the page loads site.js.

Gallery filter hides everything

Compare the filter button's data-filter with each card's data-category. For example, engineering must be spelled the same in both places.

Link goes nowhere

For a different file, check the filename in href. For a section jump, the part after # must match an element's id.

JavaScript error

Press F12 in the browser and open Console. Read the first red error. A message about null often means the script tried to use an element that is missing or has a misspelled selector.

Safest way to experiment

  1. Change one thing, then save with Ctrl + S.
  2. Refresh the browser and check the page.
  3. If it breaks, undo with Ctrl + Z and compare your edit to the example.
  4. Once it works, make the next change.
